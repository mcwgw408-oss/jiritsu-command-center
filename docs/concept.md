# 自立に向けた実験の司令塔

## 目的

情報、記録、教材、相談先、自作アプリ、商品候補、実験の結果が散らばっている状態から、必要な場所へ戻れる地図を作る。

## しないこと

- 日々のタスク管理を置き換えない
- すべての情報をこのアプリへ移さない
- 気になる種を自動的にタスク化しない
- 実験を大量に開始しない
- 期限で焦らせる管理表にしない

## 6つの領域

1. 今の現在地
2. 持っているもの
3. 情報源・相談先
4. 気になる種
5. 実験中
6. 分かったこと・次につなげること

## 既存ダッシュボードとの関係

このアプリで方向を考え、今日やることだけ既存ダッシュボードへ持っていく。
実行後、重要な結果や発見だけをこのアプリへ戻す。
