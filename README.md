# jiritsu-command-center

「自立に向けた実験の司令塔」のWebアプリです。

これは日々のタスク管理アプリではありません。方向を考え、持っているものを見渡し、試したことから分かったことを戻すための地図です。

## 6つの領域

1. 今の現在地
2. 持っているもの
3. 情報源・相談先
4. 気になる種
5. 実験中
6. 分かったこと・次につなげること

## 既存ダッシュボードとの役割分担

```text
司令塔で方向を見る
↓
今日やることだけ既存ダッシュボードへ渡す
↓
実行する
↓
重要な結果や発見だけ司令塔へ戻す
```

## 現在の主な機能

- 6つの領域を1画面で確認
- 項目の追加、編集、削除
- タグと関連リンク
- 実験の状態、開始日、次に見直す目安
- 6領域を横断する検索
- 既存ダッシュボードへのリンク設定
- JSONでバックアップ／復元
- 初期データへの復元

## 技術構成

- Vite
- React
- TypeScript
- localStorage

データはブラウザのlocalStorageに保存されます。端末やブラウザを変える場合、大きな変更の前後ではJSONを書き出してバックアップしてください。
